FUZZY LOVE - QUICK START

1. Extract the ZIP, then double-click START.cmd. Keep the terminal open.
2. Read Lea's preferences and the four profiles.
3. Adjust the fit ratings if needed: 0 = poor, 5 = moderate, 10 = ideal.
   These are your judgments, not actual ages or distances.
4. Click Calculate rankings. Compare fuzzy rules with the simple average.
   Open See fuzzy rules and calculation to inspect the engine's steps.
5. Click Use this example in survey. Participants compare A/B and answer.
   Click Save response, then Next participant.
6. Open Results for a summary. Answers are saved in results.csv.

Keep the same example for everyone. The survey runs on this computer.
Back up results.csv; close it in Excel while collecting answers.
Each computer saves its own results.csv; send that file back.

Code: fuzzy_engine.py = rankers; main.py = app and survey.
New computer: install Python 3.12, then run:
python -m pip install -r requirements.txt
